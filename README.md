# Ponkichi 記帳

剣山醸造所（株式会社パドルブリュー）の記帳アプリ。
醸造所のiPadから、入荷・欠減測定・BT移送・詰口をその場で記録する。

## 特徴

- **一問一答**：1画面1問。濡れた手・手袋でも押せる大きさ
- **オフラインで動く**：電波が無くても記録でき、つながった時に自動送信
- **二重記帳しない**：送信済みの記録は、再送しても帳簿が増えない

## 送信先について

記録の送信先URLは**この端末にだけ保存**され、プログラムには含まれていない。
初回に設定画面から入力する。

## 開発

ローカル確認用のサーバーは `_devserver.js`（このリポジトリには含めない）。
